# Contributing to TommeView

Thank you for considering a contribution.

## Before opening an issue

- Use the **Bug report** template for a reproducible defect.
- Use the **Idea or improvement** template for a feature request. Explain the
  timing-analysis workflow and constraints, rather than only proposing a UI
  control.
- Do not attach confidential videos, annotations, credentials or material you
  are not entitled to share.

## Code contributions

Discuss substantial changes in an Issue before investing in an implementation.
Keep changes focused, preserve local annotation data and avoid adding downloaded
tools, virtual environments, build output or test reports to commits.

Use four-space Python indentation, `snake_case` functions and `PascalCase`
classes. Keep model logic independent of Qt. Add or update focused tests and run
the relevant checks described in [BUILDING.md](BUILDING.md).

By submitting a contribution, you license it under GPL-3.0-or-later. Do not
submit code that you are not entitled to license under those terms.
