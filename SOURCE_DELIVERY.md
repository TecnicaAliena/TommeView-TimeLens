# Dependency source delivery

Release **v1.6.4** includes six `TommeView-dependency-sources-…` assets.
Download all parts from that same release, verify the SHA-256 values in
`dependency-source-inventory.json`, and extract them to a folder of your choice.
Every archive contains `SOURCE-INDEX.json`, mapping each source archive to its
upstream URL, revision and hash.

These assets contain third-party component sources only. They do not include
TommeView's private original code, private history, annotations, videos or
credentials. They are not required to install or use the application.
