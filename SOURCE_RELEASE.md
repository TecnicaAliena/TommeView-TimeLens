# Source-release scope

This repository publishes the original TommeView source code, build scripts,
tests, documentation and original assets needed to understand, modify and build
the project. Unless a file states otherwise, original source is GPL-3.0-or-later.

The public repository intentionally excludes the former private Git history,
personal annotations, credentials, local configuration, virtual environments,
downloaded third-party tools, generated build output, installers, test reports
and user videos. The synthetic `demo/demo.avi` fixture is included only for
source-level testing; it is not bundled in the executable or installer.

Third-party source archives for the 1.6.4 Windows package are release assets,
not repository source files. See [SOURCE_REFERENCES.md](SOURCE_REFERENCES.md)
and [SOURCE_DELIVERY.md](SOURCE_DELIVERY.md).

Use [BUILDING.md](BUILDING.md) for the reproducible build path and
[CONTRIBUTING.md](CONTRIBUTING.md) for participation guidance.
